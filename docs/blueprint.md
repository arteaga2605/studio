# **App Name**: China Visa Application Portal

## Core Features:

- User Authentication: Secure login and authentication for users to manage their visa applications.
- Visa Application Form: Dynamic form to collect all required information for the China Business Visa (Type M) application, including personal details, employment history, travel plans, and family information.
- Document Upload: Allow users to upload required documents such as passport copies, photos (following specific photo studio requirements), invitation letters, company registration documents, and other supporting files.
- Data Storage: Store user data, application details, and uploaded documents securely using a PostgreSQL database.
- Application Review: Enable administrators to review submitted applications, verify the completeness and correctness of information, and manage the application process.
- Submission Confirmation: Generate a confirmation message including any disclaimer to confirm user's responsibilities as stated in the request and that the application has been submitted successfully and is under review.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to evoke trust and reliability, mirroring the official nature of the application.
- Background color: Very light gray (#F0F0F0), providing a neutral backdrop that ensures readability and focuses attention on the form elements.
- Accent color: Soft teal (#66CDAA) to highlight important actions and notifications, complementing the primary color.
- Body and headline font: 'Inter', a sans-serif font known for its readability and modern appearance, is to be used for the main content and headings.
- Use clean, minimalist icons for form sections, document types, and navigation to enhance usability.
- Implement a responsive, single-column layout to ensure optimal viewing and interaction across different devices.
- Use subtle transitions and loading animations to provide feedback to the user and improve the perceived performance of the application.
